# 《崩坏：星穹铁道》系统拆解

以连续阅读为主的系统策划作品页，分析范围为原稿撰写时期的 3.5 版本。

## 内容维护

- 修改 `content.md` 中的正文。
- 图片保存在 `assets/`，在正文中使用相对路径引用。
- 第一个二级标题是副标题，后续二级标题自动生成章节目录；三级标题用于章内小节。
- 发布前运行 `npm install` 和 `npm run build`，更新后的网页会自动写入 `docs/`；提交正文及生成的网页文件即可更新内容。

## 网页发布

GitHub Pages 使用 `main` 分支的 `/docs` 目录。网页只依赖静态文件，无需访客登录。

作品的独立路径是 `/game_present/hsr/`。根目录暂时跳转到作品，后续可以换成个人主页，作品路径不变。

## 目录

- `content.md`：网页正文。
- `build.mjs`：生成页面和目录。
- `assets/`：正文使用的图片。
- `docs/`：GitHub Pages 发布文件。

网站最终访问地址以 GitHub Pages 部署成功后的结果为准。
